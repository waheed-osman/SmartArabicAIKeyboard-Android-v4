# لوحة القلم الذكية — Qalam AI Keyboard

لوحة مفاتيح أندرويد عربية (Kotlin + Jetpack Compose) مع أدوات ذكاء اصطناعي عبر Gemini تعمل **عند الطلب فقط**.

## المزايا
- تخطيطات: عربي، إنجليزي، رموز، ووضع «حاسوب كامل» (Ctrl+A/C/V/Z/Y، Tab، أسهم وتحديد النص).
- أدوات AI: تدقيق إملائي ونحوي، ترجمة (عربي↔إنجليزي)، تشكيل تلقائي، تغيير النبرة (رسمي/ودود/اختصار/توسيع)، إكمال الجمل.
- حافظة ذكية: تثبيت وتصنيف بالفئات، مخزّنة **مشفرة** على الجهاز، مع زر مسح وخيار تعطيل.
- **استوديو الإعلانات (AI):** ارفع صورة المنتج ← تحليل ← 3 أفكار إعلانية ← نص الإعلان ← وصف التصميم وتوليد صورة إعلانية ← حزمة محتوى (منشورات، سيناريو فيديو، هاشتاغات). كل مرحلة قابلة للتعديل وتحتاج زر «اعتمد» منك، والمشاركة لا تُفعَّل إلا بعد «الاعتماد النهائي». يُفتح من الإعدادات أو من لوحة أدوات AI في الكيبورد.
- **مزايا إضافية (زر ⚙ في الكيبورد):** حاسبة، كيبورد متحرك (أفقياً)، صوت المفاتيح، إضاءة حواف المفاتيح، سحب المسافة لتحريك المؤشر، تصحيح تلقائي واقتراحات وقاموس شخصي، إملاء صوتي، ثيم وتصميم شخصي (لون/شكل المفاتيح)، خطوط، جمل مستخدمة، إيموجي وملصقات نصية، «انسخ للترجمة» (يدوي)، تقرير الأخطاء، أسئلة شائعة.
- **تخصيص الحجم:** زر ⚙ في الكيبورد يفتح لوحة إعدادات (حجم اللوحة والأحرف بمنزلقات، صف الأرقام، اليد الواحدة، تخصيص الشريط، الثيم، اللغات).
- 4 ثيمات، تنبؤ محلي بالعبارات الشائعة، اهتزاز لمسي.

## الخصوصية
- لا يُرسل أي نص إلا عند ضغطك على زر ذكاء اصطناعي، وحينها يذهب النص المحدد (أو نص الحقل) إلى Google Gemini.
- الأدوات والتنبؤ وسجل الحافظة معطلة في حقول كلمات المرور ووضع التصفح الخفي، ويُتجاهل المحتوى الذي تعلّمه مدراء كلمات المرور كحساس.
- مفتاح API مخزَّن بـ EncryptedSharedPreferences ولا يُنسخ احتياطياً. راجع [PRIVACY.md](PRIVACY.md).

## ملاحظات استوديو الإعلانات
- توليد الصور يستخدم النموذج المعرَّف في `GeminiClient.IMAGE_MODEL` وقد يتطلب مفتاحاً بخطة مدفوعة؛ عند تجاوز الحصة تظهر رسالة واضحة.
- الصورة تُولَّد بلا نص داخلها عمداً لأن الحروف العربية في صور الذكاء الاصطناعي غير موثوقة.
- حالة العمل تُحفظ أثناء تدوير الشاشة لكن ليس بعد إغلاق التطبيق.

## البناء
راجع [BUILD_APK_GUIDE.md](BUILD_APK_GUIDE.md). أسهل طريقة: ارفع المشروع إلى GitHub وشغّل *Actions ← Build APK* ثم نزّل الـ APK.

## خارطة الطريق
- إضافة الشعار/العنوان فوق الصورة الإعلانية محلياً (نصوص عربية سليمة)، وحفظ المشاريع الإعلانية.
- توليد الفيديو (حالياً سيناريو نصي فقط).
- الكتابة بالتمرير (Glide Typing) الحقيقية (تحتاج قاموساً عربياً كبيراً) — غير متوفرة بعد.
- ملصقات صور حقيقية (الحالية نصوص جاهزة).
- قاموس عربي أكبر للتنبؤ المحلي وتصحيح الإملاء دون اتصال.
- اختبارات آلية.
